# Clipboard History - Project Baseline

## Obiettivo

Applicazione desktop locale per macOS e Windows per mantenere uno storico della clipboard e recuperare elementi precedentemente copiati tramite shortcut globali configurabili.

## Principi

- Cross-platform: macOS e Windows
- Local-first
- Nessun account obbligatorio
- Nessun cloud obbligatorio
- Keyboard-first
- Shortcut configurabili dall utente
- Privacy by design
- Documentazione tecnica mantenuta insieme al codice

## Stack

- Tauri 2
- Rust
- React
- TypeScript
- SQLite

## Requisiti MVP

1. Monitoraggio clipboard
2. Storico locale
3. Deduplicazione
4. Popup dello storico
5. Shortcut globale configurabile
6. Navigazione da tastiera
7. Incolla elemento selezionato
8. Impostazioni persistenti
9. Avvio opzionale al login
10. Documentazione tecnica macOS/Windows
