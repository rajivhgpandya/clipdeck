# Clipdeck Rebrand v0.8

## Objective

Remove company-specific branding and establish a neutral product identity.

## Product name

Clipdeck

## Identity

Clipdeck is a local-first clipboard history application for macOS and Windows.

The visual identity uses a neutral clipboard symbol.

No company logo or company-specific branding is required.

## Changes

- Product renamed to Clipdeck.
- Application title changed to Clipdeck.
- Tauri product name changed to Clipdeck.
- Bundle identifier changed to app.clipdeck.desktop.
- npm package renamed to clipdeck.
- Rust application package renamed to clipdeck.
- Company-specific logo assets removed from the active UI.
- Sidebar now uses the clipboard symbol.
- Menu bar / system tray continues to use the clipboard symbol.
- Technical documentation neutralized.
- Functional behaviour remains unchanged.

## Git

The previous v0.7.5-stable tag is intentionally preserved as the private development checkpoint.

Before publishing the repository to GitHub, the public Git history should be cleaned or squashed so obsolete private branding is not exposed in historical commits.

## Version

Clipdeck v0.8
