# Appearance and Window v0.8.2

## Window model

Clipdeck uses a fixed application width of 1100 px.

Manual resize is disabled.

Available window heights:

- 600 px
- 700 px
- 800 px
- 900 px

The selected height is persisted locally.

## Appearance

Supported modes:

- System
- Light
- Dark

## Accent color

Supported accent options:

- System
- Cyan
- Blue
- Purple
- Green
- Orange
- Pink
