# Clipboard History - UI v0.1

## Stato

Prima interfaccia grafica dell'applicazione.

Questa versione utilizza dati dimostrativi e non monitora ancora la clipboard reale.

## Interfaccia

### History

- ricerca
- elenco clipboard
- numerazione elementi
- anteprima contenuto
- tipologia contenuto
- timestamp
- pin/unpin
- cancellazione
- cancellazione completa storico

### Settings

- configurazione shortcut
- dimensione storico
- indicazione storage locale
- avvio al login

## Prossima fase

Collegamento della UI al backend Tauri:

- clipboard watcher reale
- persistenza locale
- global shortcut configurabile
- popup rapido
- incolla elemento selezionato
